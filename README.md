# El Edificio — escape cartesiano

Un point-and-click sobre las seis *Meditaciones metafísicas* de René Descartes,
para 5.º año. Se juega en el navegador y no necesita instalar nada.

Una creación del Prof. Dan Mecikovsky.

## Qué hay en esta carpeta

    index.html    el juego entero: un solo archivo, 8,7 MB
    .nojekyll     le pide a GitHub Pages que publique la carpeta tal cual

`index.html` es **autocontenido**: el HTML, el CSS, el JavaScript y las
veinticuatro imágenes viajan adentro. No sale a la red, no guarda nada en el
navegador y funciona sin internet una vez abierto.

## Cómo publicarlo en GitHub Pages

1. Subí esta carpeta al repositorio.
2. En el repo: **Settings → Pages → Source: Deploy from a branch**, rama `main`,
   carpeta `/ (root)`. Guardá.
3. Esperá un minuto. La dirección queda:

       https://<tu-usuario>.github.io/<repositorio>/edificio/

Esa es la que se les pasa a los chicos.

## Antes de la clase

Son **8,7 MB por cada vez que se abre**. Con wifi no se nota; treinta celulares
con datos son casi 300 MB. Conviene que lo abran una vez con wifi: después el
navegador se lo guarda y entra al instante.

## Si hace falta actualizarlo

`index.html` es una copia exacta de `El Edificio - escape cartesiano v5.html`,
que está en la carpeta de arriba. Ahí se trabaja; acá se copia. Para actualizar,
se pisa el archivo y se vuelve a subir — nada más.
